# Udemy-clone
This project is a static clone of the Udemy homepage, built using HTML and CSS only. It replicates the look and feel of the original Udemy website, focusing on clean, responsive design principles and semantic markup.

## Features
Header Section: Contains the Udemy logo, a search bar, navigation links (Courses, My Learning), and icons for the cart and profile actions.

Category Navigation: Horizontally scrollable category buttons such as Development, Business, IT & Software, Personal Development, Design, and Marketing.

Hero Banner: Features banner-style visuals and promotional content.

Recommended Courses: Displays cards for recommended and popular courses, with course images, ratings, instructor names, and pricing.

Topics List: Shows additional recommended topics as clickable buttons.

Responsive Design: The layout adapts to different screen sizes using CSS Flexbox and media queries.

Footer Section: Includes links to Udemy resources such as About, Careers, Blog, Support, Affiliate, and Investors.

## Tech Stack
HTML: Semantic structure of the site, including sections, navigation, and informative content.

CSS: Custom styling for sections, buttons, grid layouts, responsiveness, and interactive elements.
